# bundle/resources/document_standards

## Overview
Shared document standards referenced by EGM reviewers and skills.

## Interface
- `feature-spec-standard.md` — feature specification standard.
- `heilmeier-standard.md` — Heilmeier catechism standard.
- `implementation-readiness-standard.md` — implementation readiness standard.
- `re-implementation-standard.md` — re-implementation standard.
- `zoom-out-standard.md` — zoom-out review standard.

## Invariants
- Standards are authoritative; skills link to them rather than duplicating rules.

## Side Effects
- None; read-only reference assets.

## Verification
- Run: `npm run validate`
